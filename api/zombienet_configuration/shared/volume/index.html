Module volume 

Source
Expand description

Volumes backed by a kubernetes PersistentVolumeClaim, mounted into a node or a custom process (only k8s).

A volume is a mount_path plus where its storage comes from:

  • a template (no claim): a claim provisioned for the pod, size (DEFAULT_VOLUME_SIZE when absent), on storage_class (the cluster’s default when absent), optionally filled from a VolumeSnapshot or another claim. It lives and dies with the pod.
  • an existing claim, by name, in the namespace the network runs in. zombienet never creates nor deletes it.

A volume on /cfg, /data or /relay-data takes the place of the scratch volume zombienet mounts there; any other path is mounted as well.

[[relaychain.nodes.volumes]]
mount_path = "/data"
size = "100Gi"
storage_class = "premium-rwo"

[[relaychain.nodes.volumes]]
mount_path = "/opt/fixtures"
claim = "fixtures"
read_only = true
