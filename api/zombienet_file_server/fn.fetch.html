pub(crate) async fn fetch(
    __arg0: Path<String>,
    __arg1: State<AppState>,
    body: String,
) -> (StatusCode, String)
Expand description

Fetch the URL in the request body into file_path, so a large file never has to pass through whoever runs zombienet.

Idempotent, so the same request both starts the fetch and polls it:

  • 200 once the file is there, also straight away if it already was;
  • 202 while the fetch runs, with the bytes written so far;
  • 502 once, if the fetch failed (the next PUT starts it again).

The file only appears, under its name, when it is complete: a fetch writes to <file_path>.part and renames it at the end.
